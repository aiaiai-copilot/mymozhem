# Architecture Decision Records

На текущем этапе все принятые ADR (001…011, включая 005a) консолидированы в главном нормативном документе: [`../spec/normative-package-v1.2.md`](../spec/normative-package-v1.2.md), раздел 1.

Эта директория — место для **новых** ADR, принимаемых по ходу разработки. Правило REQ-DEV-004: любое отклонение от действующего решения оформляется новым ADR **до** слияния кода, а не постфактум.

## Индекс действующих решений (в spec)

| ADR | Тема | Суть |
|---|---|---|
| 001 | Продуктовая рамка | Платформа для своих приложений, единый артефакт; НЕ мультитенантный BaaS |
| 002 | Модель исполнения | Модульный монолит, одна реплика; граница ядро↔модуль через SDK, охраняется CI |
| 003 | Домены ядра | Ядро = Identity/Room/Membership/Realtime/App-registry; rewards — опц. модуль; уровни видимости |
| 004 | Гостевой доступ | Вход по коду без регистрации (дефолт); единая identity с kind REGISTERED\|GUEST |
| 005 | Состояние игры | Append-only event log комнаты; проекции; «первый» = порядок в логе |
| 005a | Транспорт | Socket.io за контрактом ядра, сменяем |
| 006 | Стек и контракт | NestJS + Prisma; zod-контракт в SDK как единственный источник истины |
| 007 | Награды | MVP — только очное вручение; заочный claim отложен |
| 008 | Видимость исхода | Поле-уровневая видимость appSettings; ядро отклоняет мислейбл событий |
| 009 | Арбитраж «первого» | Окно приёма против бота; payload-нейтральность гонки за seq |
| 010 | Розыгрыш | Серверный CSPRNG; публичная верифицируемость (VRF) отложена |
| 011 | Инсайдер | MODERATOR как актор угроз T5; аудит и лимиты его действий |

## Формат нового ADR

```
# ADR-NNN — <заголовок>
Статус: предложен | принят | заменяет ADR-XXX | заменён ADR-YYY
Дата:
Контекст: <что вынудило решать>
Решение: <что решили>
Мотивация: <почему так>
Следствия: <что меняется, какие требования затрагиваются>
Отклонено: <альтернативы и почему>
```
