# LOC-снапшоты — статистика строк исходников

Датированные замеры размера кодовой базы для сравнения между фазами.
Новый снапшот — новая строка в таблицах + дата и якорь (фаза/срез) в журнале ниже.

## Методика (соблюдать при следующих замерах, чтобы сравнение было честным)

- Дерево: `apps/`, `packages/`, `scripts/` репозитория.
- Исключено: `node_modules`, `dist`, `.turbo`, `coverage`, сгенерированный Prisma-клиент (`generated/`).
- Включённые расширения: `.ts`, `.js`, `.mjs`, `.mts`, `.prisma`, `.sql`.
- «Тесты» = файлы `*.spec.ts`, `*.int-spec.ts`, `*.e2e-spec.ts` и содержимое `test/`.
- «Миграции» = `packages/*/prisma/migrations/**/*.sql`.
- Доки (`docs/**/*.md`) считаются отдельно, в сумму кода не входят.
- `cloc`/`tokei` на машине нет — замер командой `find … -exec cat {} + | wc -l` (см. сессию 2026-08-02).
